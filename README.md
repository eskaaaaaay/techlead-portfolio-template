# ⚡ Enterprise Tech Lead & Senior Architect Portfolio Template

A modern, high-performance dark mode single-page portfolio designed for **Technical Leads, Senior Software Engineers, and Solution Architects**.

---

## 🚀 Quick Start (Customize in 2 Minutes)

All text, roles, skills, experience milestones, education, and links are managed from **a single configuration file**:

👉 **`src/data/portfolioData.js`**

Simply open `src/data/portfolioData.js` and edit the values.

---

## 🤖 AI Generation Blueprint (`PROMPT.md`)

Want to use **Antigravity**, **Cursor**, **Claude**, or **ChatGPT** to automatically customize this entire portfolio from your LinkedIn profile or resume?

Check out **[`PROMPT.md`](./PROMPT.md)** — a master prompt engineered with all the design tokens, mobile performance rules, and architecture guidelines. Just paste your resume into the prompt and let the AI populate `portfolioData.js`!

---

## 🛠️ Development & Build Commands

```bash
# Install dependencies
npm install

# Run local dev server (http://localhost:5173)
npm run dev

# Build production bundle for deployment (outputs to dist/)
npm run build
```

---

## 🌐 1-Click Netlify Deployment

1. Run `npm run build` (or use the pre-built `dist/` folder).
2. Go to **[app.netlify.com/drop](https://app.netlify.com/drop)**.
3. Drag and drop the `dist/` folder (or `deploy.zip`).
4. Your portfolio is live with free SSL!

## 🎨 Tech Stack & Highlights
- **React 19 + Vite 8**
- **Tailwind CSS v4** (using modern theme variables)
- **Framer Motion** (hardware-accelerated 120fps/60fps animations)
- **Interactive Cursor Spotlight** (Linear/Vercel standard)
- **100% Mobile Optimized** (zero scroll jank, responsive touch interactions)
- **Dark Mode Enterprise Palette** (True black `#09090B` with Microsoft .NET Purple `#512BD4` accents)
